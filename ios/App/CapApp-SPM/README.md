# CapApp-SPM

Project-owned local package for Cash Weave's iOS native dependencies.

Capacitor is pinned exactly to 8.5.3 and iOS minimum is 15.4. Use the repository's `npm run ios:sync`; a generic Capacitor sync can rewrite this reviewed package. Native package resolution/cache preparation is a separate operator step on macOS. Offline analyze/build never resolves or updates packages automatically.
